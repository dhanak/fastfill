FastFill development build - macOS universal (Intel and Apple silicon)

Extract this ZIP. Open FastFill-Rust.app from the extracted folder. No Rust
toolchain, compiler, .NET, or installer is needed. This is an experimental
build; the production C#/WinUI application is unchanged.

The app is ad-hoc signed to seal its code and bundle, but it has no Developer
ID certificate and is not notarized. Gatekeeper may block the first launch.
Only if you trust this download, try opening it once, then use System Settings
> Privacy & Security > Open Anyway. Do not disable Gatekeeper globally.

Open an image, PDF or .docscan from inside the app. Save a copy of valuable
projects while testing. Print sample-form.pdf at actual size for form checks.
Camera capture is not yet supported on macOS; Linux and Windows have native
camera backends. Use F1 or the Shortcuts button for in-app controls. For
startup diagnostics, launch the app binary from Terminal and keep its output:
FastFill-Rust.app/Contents/MacOS/FastFill-Rust

See BUILD.txt for the exact source revision and workflow run.

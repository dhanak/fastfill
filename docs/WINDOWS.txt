FastFill - Windows x64

Extract this ZIP anywhere. Run FastFill.exe from the extracted folder.
No compiler, managed runtime, installer or separate Visual C++ runtime is
required. Windows 10/11 x64 is the target platform.

Public master/tag packages use the persistent FastFill signing certificate.
Unsigned branch and pull-request packages omit FastFill.cer. If you trust the
public download, open FastFill.cer, choose Install Certificate, Current User,
and Trusted Root Certification Authorities. Existing trust remains valid.
Self-signing does not guarantee SmartScreen or Smart App Control approval.

Open images, PDFs and .docscan projects in the app. A .docscan path can also
be passed on the command line. Save editable projects before exporting PDFs.
Print sample-form.pdf at actual size for camera/form checks.
See BUILD.txt for the exact source revision and workflow run.
